Concrete Strength Modeling

An engineering regression workflow combining autoencoder-based data refinement, model comparison, and metaheuristic parameter search. Saved prediction curves, error comparisons, and a Taylor diagram document the behavior of the tested models.

Abstract

Predicting concrete-related mechanical behavior from experimental variables requires attention to both the quality of the observations and the flexibility of the regression model. This study investigates a machine-learning workflow that combines autoencoder-based data refinement with regression and metaheuristic hyperparameter search. The objective is to reduce the influence of poorly reconstructed observations and identify model settings that capture the relationship between the available input features and the target strength measure.

The documented procedure trains an autoencoder to reconstruct the tabular inputs and uses reconstruction error to identify observations for filtering. The network contains hidden layers with 64 and 32 units and is trained using Adam and mean squared error. Several regressors are then compared on the refined dataset, including Random Forest, support-vector regression, XGBoost, linear regression, and a multilayer perceptron. Random Forest hyperparameters are explored using several population-based optimizers. The evaluation reports error measures and explained variance, while the notebooks retain prediction curves, model-comparison plots, and a Taylor diagram.

The recorded initial model comparison reports a test R² of 0.8543 for Random Forest and 0.8332 for XGBoost. Other tested models show substantially weaker behavior in the same comparison, illustrating the importance of evaluating model families on the actual engineering dataset. The subsequent optimization work studies parameter choices for the selected regression approach. The contribution is an implemented experimental pipeline that links data reconstruction, sample refinement, predictive modeling, and optimization with saved analytical outputs. The accompanying figures make differences in model behavior visible and complement the numerical summaries. Together, they document a practical investigation of how preprocessing and parameter selection affect regression performance in an engineering application, while preserving the context of the reported test results.
