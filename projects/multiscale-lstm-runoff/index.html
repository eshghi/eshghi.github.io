Multi-Timestep LSTM Runoff

An ensemble of LSTM regressors that learns from several recent time windows and uses particle swarm optimization for parameter selection. Evaluation on later observations connects error measures with annual and monthly prediction traces.

Abstract

Accurate river runoff prediction is a fundamental pillar of sustainable water resources management and plays a crucial role in mitigating the impacts of natural disasters, supporting agricultural planning, and enhancing flood control strategies. In this study, we focus on the Ajichay River, a significant tributary of Lake Urmia in northwestern Iran, which has faced increasing hydrological challenges in recent decades. We propose a robust and advanced Long Short-Term Memory (LSTM) neural network based regressor to predict daily runoff. The dataset used consists of 1,604 daily samples collected between 2010 and 2018. The proposed model employs an architecture composed of five distinct LSTM models, each trained with different time step intervals ranging from 2 to 6 days to capture multi-scale temporal dependencies in the hydrological data. To optimize the model’s performance, key parameters of each LSTM component were fine-tuned using Particle Swarm Optimization (PSO), an efficient population-based metaheuristic algorithm. The hybrid model was evaluated on unseen data from 2017 to 2018 using three statistical metrics: the coefficient of determination (R²), Root Mean Square Error (RMSE), and Mean Squared Error (MSE). The results demonstrate high predictive accuracy, with R² values ranging from 74.95% to 91.42%, indicating the strong generalization capability of the proposed method. In addition, a comprehensive feature importance analysis was conducted using multiple interpretability techniques, shedding light on the influence of individual input variables on runoff predictions.

Using several input windows allows the ensemble to represent hydrological effects that operate over different recent histories. Each branch receives a distinct temporal view, and optimization tunes the component models before their predictions are combined. Evaluation on a later time period separates the forecasting task from fitting the observed training sequence. The accompanying comparisons examine ensemble size and show observed and predicted runoff over annual and monthly periods. These views reveal how the prediction follows changes in the river record and complement the aggregate error measures. The contribution is a multi-window forecasting design that combines temporal representation, parameter search, and model interpretation within one hydrological prediction study.
