Defragmentation

A working tool for organizing documents into semantic trees and retrieving information through their branches. Defragmentation combines hierarchical text organization, cosine and learned scoring, and interactive views of search paths and proposition relationships.

Abstract

Long documents often contain useful information at several levels of detail, from broad topics to individual statements. Defragmentation, developed in the code collection as NLP Graph, investigates how a hierarchical representation can make this structure explicit and support targeted retrieval. The objective is to organize text into semantic units, retain their parent-child relationships, and retrieve relevant content through an observable route through the hierarchy.

The application builds and displays semantic trees and supports additional proposition-level relationship graphs. Its retrieval implementation compares a direct cosine-similarity scorer with a learned multilayer perceptron. The learned scorer combines query and node embeddings with their absolute difference, elementwise product, and cosine similarity. Search starts at the root and ranks the direct children of selected nodes. Thresholds, top-k selection, and beam width control how many branches remain active and how deeply the query is explored. The interface exposes the resulting paths, visited and rejected nodes, final leaves, and scores, so a user can inspect how a result was reached.

The existing application contains saved project trees, relationship graphs, and retrieval outputs. These records demonstrate that the representation and search workflow have been implemented and used. The interface images show those structures through the application's own visualization code. The main result is a usable system in which semantic organization and hierarchical retrieval are connected to visual inspection. Comparing the two scorers within a shared traversal procedure makes scoring behavior easier to distinguish from search-policy effects. The project contributes software for studying structured language retrieval and provides an experimental setting for evaluating relevance, traversal efficiency, and the effects of retaining different branches of a document hierarchy. The portfolio presents this functional outcome without assigning an unverified retrieval benchmark score.
