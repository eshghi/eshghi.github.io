AI-assisted Academic Advising

A hybrid advising system combining cluster-specific grade prediction with a rule-based recommendation engine. The deployed workflow translates an ensemble forecast into probation warnings, GPA estimates, and course guidance for students.

Abstract

The rapidly increasing student population has posed serious challenges to the traditional academic advising process. This study designs and implements a multi-purpose intelligent system to support students' academic progress, based on a two-part hybrid framework: (1) an advanced model for grade prediction and (2) a rule-based recommendation engine. Using a dataset containing 416,558 educational records from the University of Birjand, students were first divided into homogeneous clusters using the Gaussian Mixture Model (GMM). Subsequently, a Stacking Ensemble model combining Random Forest, Gradient Boosting, and MLP was trained specifically for each cluster. Evaluation results demonstrated that the Stacking model outperformed base models across all clusters, achieving a final aggregated RMSE of 2.35. The second component is an expert system that provides intelligent recommendations by synergizing educational regulations with the grades predicted by the first component. This system has been implemented as a practical tool on the University of Birjand portal, offering students real-time feedback such as semester GPA prediction, probation risk warnings, and course suggestions for GPA improvement.

The prediction and recommendation components address complementary parts of academic advising. The ensemble estimates likely course outcomes from the educational record, while the expert system converts those estimates into recommendations constrained by academic rules. Clustering allows the prediction models to account for groups of students with different record patterns before the base learners are combined through stacking. The analysis compares ensemble and individual-model performance within these groups and aggregates the errors across the full evaluation. The advising interface then presents the consequences in terms that students can use, including expected semester performance and possible course choices. This connection between predictive modeling and explicit institutional rules is the central contribution of the framework. The resulting system demonstrates an end-to-end application in which numerical forecasts support understandable academic recommendations and can be inspected through student-facing reports.
